\mysection{Background}{Background}
\label{sec:background}

Given data from many hours of recordings which contains whale noises at 
undetermined times is difficult to analyse where these whale sounds occur 
at a glance. This is of interest as researchers can use this information 
to determine the migration patterns of whales and other behaviours.

\mysection{Problem Statement}{Problem Statement}
\label{sec:problemstatement}

Determine whether using Dynamic Time Warping (DTW) in the frequency domain, thus 
using vector features, improves the ability of DTW to detect and classify whale 
calls compared to the time-domain approach of Dynamic Time Warping, thus using scalar features.
The methods used will be Short Time Fourier Transform (STFT), 
Mel-frequency Cepstral Coeffficients (MFCC) and Linear Predictive Coding (LPC).

\mysection{Objectives}{Objectives}
\label{sec:objectives}

The DTW method in the time domain will first be implemented. The scalar features will be used
from the data as it is given in the file.

The DTW method in the frequency domain will then be implemented using three different extraction methods 
to ensure that the comparison between sacalr and vector features does not depend on how the vector
features are chosen. The methods used will be Short Time Fourier Transform (STFT), 
Mel-frequency Cepstral Coeffficients (MFCC) and Linear Predictive Coding (LPC).

The four models will then be compared to determine which method is best for whale detection 
and to determine whether the frequency domain approach is better and if so, how significant 
the improvements are.
