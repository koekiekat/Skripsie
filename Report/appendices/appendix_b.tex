\section{Complex Engineering Problem}\label{sec:ecsa_1}
A systematic, theory-based method was used to design the Bryde's whales 
call detection system. The systematic approach can be seen in the report 
structure. Engineering specialist knowledge can be seen in the 
theory and mathematics behind all engineering concepts needed 
for this project. This was researched and described in Chapter~\ref{chap:literature}. 
After understanding the concepts a systematic approach was used for all 
design decisions. This included backing all design choices with sources or 
by testing as hyperparameters. This can be seen in Chapter~\ref{chap:sys-design}.

As seen in Chapter~\ref{chap:sys-design} efficient use of resources 
was considered, thus, the 72 hour audio 
file which had to be processed was split into 1 hour segments for analysis 
to ensure efficient use of device memory. 

As seen in Chapter~\ref{chap:dataset} the data used for the project 
came from previous projects, therefore resources were re-used instead of 
capturing new data. 
The real world uses of a whale call detection system 
were considered. A system such as this could be used to protect a Bryde's 
whale colony from harm caused by shipping vessels. This was explained in 
Chapter~\ref{chap:introduction}.

Engineering technology used in this project included libraries such as Python, 
Librosa, SciPy and NumPy.

In Chapter~\ref{chap:literature} articles considering different approaches 
to a similar problem or using similar methodologies for different problems 
were considered.

As explained in Chapter~\ref{chap:dataset} technical issues within 
this project included a scarcity in well labelled 
data which required creative thinking and planning for the hyperparameter 
selection stage. These issues required the solution of sub-problems (such 
as the data scarcity) in order to solve the larger problem.


\section{GA 1: Problem Solving}\label{sec:ga_1}

As explained in Chapter~\ref{chap:introduction} and~\ref{chap:dataset} 
the problem of Bryde's whale call detection in a continuos audio file with 
a scarcity of labelled data was identified. Literature relating to the problem 
was considered in the form of other implementations of similar solutions. 
The theory behind solution decisions was studied and explained in detail. 
These topics include DTW, subsequence DTW, STFT, MFCC and LPC as well as 
precision-recall (PR) analysis. The literature and theoretical explanations 
were explained in Chapter~\ref{chap:literature}.

Chapter~\ref{chap:literature} also shows understanding of the whale 
call structure and its effect on decision made for the detection pipeline.

Chapter~\ref{chap:introduction} showed that sustainability impact 
of the project was considered in the form of the uses 
of such a detection system to prevent the harm of Bryde's 
whales in False Bay.

The analysis of the detection system was done using precision, recall, 
f1-score and average precision (AP). These are all topics researched and 
explained in Chapter~\ref{chap:sys-design}. The use of these analysis methods 
to draw conclusions can be seen in Chapter~\ref{chap:results} and~\ref{chap:conclusion}.

\section{Sustainable Development}\label{sec:ecsa_2}

As explained in Chapter~\ref{chap:dataset} the dataset was re-used 
from a previous project, therefore time and resources 
was not put into capturing new whale call recordings. This is in line with 
sustainable development. 

As seen in Chapter~\ref{chap:introduction} the use of such a 
detection system in a real world application of preventing harm 
to Bryde's whales in False Bay was considered and discussed. This could 
help reduce the environmental impacts of human activties in 
whale territory.

\section{Emerging Technologies}\label{sec:ecsa_4}

An incorporation of Artificial Intelligence(AI) with a call detection system 
such as the one described in this project could be benificial for helping identify 
when whales enter vessel heavy areas of their migration region. With an AI 
prediction and alert system could be implemented along a colonies migration 
region such that vessel traffic can be diverted before Bryde's whales enter 
the vessel area.
