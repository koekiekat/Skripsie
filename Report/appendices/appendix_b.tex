\section{Complex Engineering Problem}\label{sec:ecsa_1}
The project required theory and specialist knowledge for many topics 
including: dynamic time warping (DTW), subsequence DTW, short time Fourier 
transform (STFT), mel-frequency cepstral coefficients (MFCC) and linear predictive 
Coding coefficients (LPCC).
These topics were theoretically and mathematically explained within this project.
The 72 hour data was split into 1 hour segments for analysis. This was done 
as it decreased the amount of memory used at one time. 
Engineering technology used was in the form of libraries such as Python, 
Librosa, SciPy and NumPy.
Other approaches to similar problems were analysed in the form of a literature 
review.

Technical issues within this project included a scarcity in well labelled 
data which required creative thinking and planning for the hyperparameter 
selection stage.
All data used was from previous projects.
A systems approach was used in the form of template selection, hyperparameter 
selection, detetcion pipeline and evaluation.
