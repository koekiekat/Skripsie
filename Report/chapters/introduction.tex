\mychapter{Introduction}{Introduction}{}\label{chap:introduction}

\mysection{Background}{Background}\label{sec:background-overview}
Van Waerebeek et al.~\cite{vessel_collision_since_1990s} reported indications since the late 1990s 
that whales have been struck by shipping vessels. 
Today this has become a larger concern, as vessel speeds and traffic have substantially increased. 
Bryde's whales are found to migrate in smaller regions 
instead of the usual large-scale migrations of other whale species. Faustmann et al.~\cite{bryde_whales_SA} 
report that such a whale colony in False Bay, 
South Africa has also been placed in possible danger due to fishing activities in their migration region.

Detection and classification systems for whale calls can be used to monitor the migration patterns of 
specific whale colonies throughout 
the year. The information gained from such analysis can help determine when vessel traffic should be 
diverted for the safety of a 
whale population.
These types of systems have been implemented on different whale colonies, as discussed by Betz et 
al.~\cite{reducing_vessel_collisions}, but the migration patterns of the False Bay colony have not 
yet been thoroughly documented. 
Due to the variations in call types between different colonies of some whale species, such as killer 
whales (Deecke et al.~\cite{killer_whale_dialects}) and blue 
whales (McDonald et al.~\cite{blue_whale_song_variation}), models trained for other Bryde's whale 
colonies would not be completely trustworthy for the detection of 
calls within the False Bay Bryde's whale colony, as the universality of calls cannot be assumed. 
Therefore, a model trained specifically for the False 
Bay colony would be beneficial. 

Brown et al.~\cite{DTW_has_worked} showed that \ac{DTW} is an effective method for classifying 
killer whale vocalizations. Given the 
limited labeled data for the False Bay colony, \acs{DTW} is considered as Herreilers et 
al.~\cite{dtw_few_temps} found that it requires less input data than other detection algorithms.

\mysection{Problem Statement}{Problem Statement}\label{sec:problemstatement}

This project will investigate whether dynamic time warping (DTW) applied to two-dimensional time-frequency representations 
can effectively detect Bryde's whale calls in False Bay, as measured by \gls{precision}, \gls{recall} and the \gls{f1_score}.
Three feature extraction methods will be compared in terms of detection performance. These will be the \ac{STFT}, 
\ac{MFCC} and \ac{LPCC}.

\mysection{Objectives}{Objectives}\label{sec:objectives}

\begin{enumerate}
    \item Implement a \acs{DTW}-based detection system using three feature extraction methods: 
    the short-time Fourier transform (STFT), mel-frequency cepstral coefficients (MFCCs) and 
    linear predictive coding coefficients (LPCC). 
    \item Tune the feature frame length, call type 
    thresholds and vote fraction for each method based on \gls{f1_score}.
    \item Evaluate the detection performance of each configuration using \gls{precision}, \gls{recall}, \gls{f1_score} 
    and average precision (\acs{AP}).
\end{enumerate}

\mysection{Scope}{Scope}\label{sec:scope}
    Elements not considered within this project include the classification of call types after 
    detection, the detection of tonal downsweep calls, detection algorithms other than \acs{DTW}, 
    feature extraction methods other than \acs{STFT}, \acs{MFCC} and \acs{LPCC}, the accuracy of 
    detected start and end times, the detection of frequencies above 500 Hz.

    Call type classification was not considered due to discontinuities in how calls were labeled. 
    These discontinuities arose due to a variety of 
    human labelers for different sections of data and the presence of similar frequency components 
    across different call types.

    Tonal downsweep calls were excluded from the evaluation because labeled examples of this call 
    type were only found in one of the three recordings.

    Detections were evaluated on whether they overlap a labeled call, so the accuracy of the detected 
    start and end times was not evaluated. Frequencies above 500 Hz were not considered, since the 
    audio was downsampled to 1 kHz.
